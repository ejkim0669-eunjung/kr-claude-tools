세무법인 역삼의 이번 달 급여 지출품의서와 사회보험 지출품의서를 작성해줘. (이 PC(DESKTOP-9VHJIM0)에서 매월 24일~말일 매일 오전 11시(한국 시간)에 실행되는 예약 작업. 완료 여부는 아래 0번 규칙으로 판단한다. 사용자는 자리에 없을 수 있으니 질문 대신 합리적으로 판단하고, 결과와 확인 필요 사항을 마지막에 짧게 정리할 것. 주민번호 등 개인정보는 답변에 적지 말 것. 비밀번호 입력·로그인은 하지 말 것.)

[0. 실행 여부 판단 — 가장 먼저]
- 이 작업은 24일에 처음 실행되고, 성공할 때까지 다음날 같은 시각에 다시 실행된다.
- 먼저 품의서 파일(아래 3번 경로)의 맨 앞 시트들을 확인해 이번 달(가장 최근 귀속월) "YYYYMMDD급여" 시트가 이미 있으면 → 이미 완료된 것이므로 아무것도 하지 말고 "이번 달 품의서는 이미 작성됨"이라고만 짧게 알리고 종료. (사회보험 시트만 빠져 있으면 사회보험 부분만 이어서 진행)
- 오늘(한국 시간)이 토요일·일요일 또는 대한민국 공휴일(대체공휴일 포함)이면 → 작업하지 말고 "오늘은 휴무일이라 내일 11시에 다시 조회합니다"라고 알리고 종료.
- WEHAGO가 로그인 화면이거나 접속이 안 되거나, Chrome 확장에 연결이 안 되면 → 작업을 멈추고 "로그인(또는 연결)이 안 되어 내일 11시에 다시 조회합니다"라고 알리고 종료. 다음날 자동 재실행된다.

[1. 급여 금액 — WEHAGO T 급여자료입력에서 직접 가져오기]
- 사용자의 Chrome(Claude in Chrome 확장, mcp__claude-in-chrome__* 도구)의 새 탭에서 https://www.wehago.com/#/main 을 연다. 로그인 화면이면 위 0번 규칙대로 종료.
- 수임처 검색창에 848-87-03021 입력 → "[본점] 세무법인 역삼" 행의 SmartA 10 "급여" 버튼 → 새 탭(smarta.wehago.com humanresource)에서 근로소득관리 > "급여자료입력" 메뉴.
- 안내 팝업은 확인/ESC로 닫는다. 상단 "지급일자" 버튼을 누르면 "근로소득 이동, 복사, 삭제" 창에 귀속월별 순인원/총지급액이 나온다. 가장 최근(총지급액이 있는 마지막) 귀속월을 클릭하면 오른쪽에 지급구분·지급일자·인원·총지급액·순지급액이 나온다.
- 급여 품의 금액 = 순지급액(차인지급액), 품의일·결재일·취급예정일·하단날짜 = 지급일자. (예: 2026년 9월 귀속 → 지급일 2026-10-02, 순지급액 22,609,447원, 총지급 25,755,937원, 7명). 확인 후 ESC로 창을 닫는다. 아무것도 수정·삭제·복사·이동하지 말 것.
- 대상 월 = 그 귀속월. 품의서 파일 맨 앞 시트에 이미 같은 지급일(YYYYMMDD급여) 시트가 있으면 이미 작성된 것이므로 건너뛰고 알린다. 이번 달 급여자료가 아직 입력되지 않았으면(최근 귀속월이 이미 품의서에 있는 달) 작성하지 말고 "급여자료 미입력 — 내일 다시 조회"라고 알리고 종료.

[2. 사회보험 금액 — 고지내역조회 PDF]
- 원천 폴더의 "<N>월" 하위폴더, 바탕화면, 다운로드 폴더에서 해당 월 사회보험 "고지내역조회"(h-well 사회보험통합징수포털 사업장 전체 고지산출 내역) PDF를 찾는다.
- 금액 = 건강+장기요양 납부할금액 + 연금 납부할금액 + 고용 납부할금액 + 산재 납부할금액 합계 (예: 9월분 2,132,180+1,966,860+429,300+157,060=4,685,400원). 날짜는 급여 지급일과 동일.
- PDF를 못 찾으면 사회보험 품의서는 만들지 말고, 급여 품의서만 작성한 뒤 어떤 파일을 어디(원천\<N>월 폴더)에 넣어두면 되는지 알려준다(다음날 실행 때 PDF가 있으면 사회보험만 이어서 작성). 찾았으면 그 PDF를 원천\<N>월 폴더에 "고지내역조회_세무법인 역삼_YYYY년 N월분.pdf"로 저장한다.

[3. 품의서 작성 — 반드시 이 방식]
- 파일: C:\Users\admin\Desktop\김은정 거래처\법인\2026년 법인자료\세무법인 역삼\원천\역삼세무회계 품의서 양식 (급여등).xlsx (연도가 바뀌면 같은 구조의 해당 연도 폴더를 찾을 것)
- 파일을 임시 폴더에 복사해서, 기존 가장 최근 "YYYYMMDD급여" 시트와 "YYYYMMDD 사회보험" 시트를 XML 수준에서 복제한다(openpyxl로 통째로 저장 금지 — 이미지·인쇄설정 손상). 복제 시트에서 G6(품의제목 "N월 직원급여"/"N월 사회보험"), E14(적요 동일), G11(금액 한글표기 "일금…원정(\금액)"), M14(금액), G8·V8·Y14·B34(지급일 날짜 시리얼)만 바꾼다. 문자열은 inlineStr.
- 시트 이름 "YYYYMMDD급여", "YYYYMMDD 사회보험"(YYYYMMDD=지급일). 순서: 맨 앞 사회보험, 다음 급여, 그 뒤 기존 시트. workbook.xml sheets·definedNames(localSheetId 재번호, Print_Area 'B2:AD36' 추가)·rels·[Content_Types].xml 갱신. 새 사회보험 시트(없으면 급여 시트)를 활성 탭으로.
- openpyxl로 열어 값 검증 후 원래 경로에 덮어쓰기. 엑셀에서 열려 잠겨 있으면 엑셀로 그 통합문서만 닫고 재시도.

[4. 인쇄] 컴퓨터 제어(Excel 2016)가 가능하면 새로 만든 시트만 각각 인쇄(Ctrl+P, 활성 시트 인쇄, Samsung M263x) 후 파일을 닫는다. 불가하면 인쇄는 생략하고 알린다.
