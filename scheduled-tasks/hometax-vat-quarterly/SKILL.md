홈택스에서 부가가치세 신고용 자료 4종을 조회해 PDF로 저장해줘.

(이 PC(DESKTOP-9VHJIM0)에서 1·4·7·10월 13~16일 오전 9시(한국 시간)에 자동 실행되는 예약 작업. 사용자는 자리에 없을 수 있으니 질문하지 말고 합리적으로 판단해 진행하고, 마지막에 결과와 확인 필요 사항을 짧게 정리할 것. 비밀번호·공동인증서 입력과 로그인은 하지 말 것. 주민번호 등 개인정보는 답변에 적지 말 것. 브라우저는 사용자의 Chrome(Claude in Chrome 확장, mcp__claude-in-chrome__* 도구)을 사용하고, 새 탭에서 작업할 것.)

[0. 실행 여부 판단 — 가장 먼저]
- 완료 기록 파일 C:\Users\admin\.claude\scheduled-tasks\hometax-vat-quarterly\done_YYYY-MM.txt (YYYY-MM = 이번 달)가 있으면 "이번 분기 자료는 이미 저장됨"이라고만 알리고 종료.
- 오늘(한국 시간)이 토·일요일 또는 대한민국 공휴일(대체공휴일 포함)이면 작업하지 말고 "휴무일이라 내일 09시에 다시 실행합니다"라고 알리고 종료.
- 홈택스가 로그인 화면이거나 접속이 안 되면 멈추고 "홈택스 로그인이 필요합니다 — 로그인해 두시면 내일 09시에 다시 실행합니다"라고 알리고 종료. (16일이 마지막 재시도)

[1. 대상 기간 — 직전 분기]
- 1월 실행: 전년 10~12월 (2기 확정) / 4월: 1~3월 (1기 예정) / 7월: 4~6월 (1기 확정) / 10월: 7~9월 (2기 예정)

[2. 조회·저장할 4종] https://www.hometax.go.kr 에서 각 메뉴를 상단 검색창에 메뉴명으로 검색해 찾는다.
 a. 부가가치세 신고자료 통합조회 → 폴더 "부가세신고자료"
 b. 부가가치세신고용 합계표 조회 → 폴더 "부가가치세신고용합계표"
 c. 신용카드·판매(결제)대행 매출자료 조회 → 폴더 "신용카드판매대행매출"
 d. 현금영수증 가맹점 매출자료 조회 → 폴더 "현금영수증가맹점매출"
- 폴더는 모두 C:\Users\admin\Desktop 아래에 두고, 없으면 만든다.
- 파일명: <폴더명>_YYYY년M월D일.pdf (실행일 기준, 예: 부가세신고자료_2026년10월13일.pdf). 같은 이름의 파일이 이미 있으면 그 항목은 건너뛴다.
- 조회 결과 화면을 홈택스의 인쇄 기능 → "PDF로 저장"으로 저장한다. 다운로드 기능을 쓸 때는 받은 파일을 위 폴더·파일명으로 옮긴다.
- 조회 결과가 없으면 "자료 없음"으로 기록하고 다음 항목으로 넘어간다. 한 항목이 실패해도 나머지는 계속 진행한다.
- 로그인한 사업자 기준으로 조회한다. 세무대리인 화면이라 수임 사업자를 골라야 하는 경우에는 임의로 고르지 말고 "대상 사업자 지정 필요"로 보고한다.
- 조회만 할 것. 신고서 작성·제출·수정 등 다른 동작은 하지 말 것.

[3. 마무리]
- 4종이 모두 저장(또는 "자료 없음" 확인)되면 done_YYYY-MM.txt를 만들고 저장한 파일 목록을 적는다. 일부만 저장됐으면 만들지 않는다(다음날 빠진 것만 다시 진행).
- 저장된 파일 경로, 자료 없음 항목, 실패 항목과 이유를 짧게 보고한다.
